# 입력기 고정

macOS에서는 특정 상황에서 입력 소스가 자동으로 ABC 등 다른 키보드 레이아웃으로 전환될 수 있습니다. **입력기 고정** 기능을 활성화하면 Ongeul이 자동으로 다시 선택되어, 의도치 않은 입력 소스 전환을 방지합니다.

## 켜고 끄기

[설정](../preferences.md)의 **"입력기 고정"** 체크박스로 켜고 끕니다. 기본값은 켜짐입니다.

## 동작 방식

- macOS 입력 소스 변경 알림을 감시합니다.
- ABC, U.S. 등 **영문 키보드 레이아웃**으로 전환이 감지되면 자동으로 Ongeul로 복원합니다. 이 전환은 영문 입력을 위한 것이므로 Ongeul의 **영문 모드**로 복원됩니다. 한글 모드로 입력하던 중이었어도 영문 모드가 되며, 그 앱에 기억된 모드도 영문으로 바뀝니다. (Ongeul 영문 입력 소스를 추가하지 않은 경우에는 한글 모드로 복원됩니다.)
- 일본어, 중국어 등 **다른 입력기(IME)**로의 전환은 허용합니다. 러시아어, 그리스어처럼 영문을 입력하지 않는 키보드 레이아웃도 같습니다. 의도적으로 다른 입력기를 선택한 경우에는 간섭하지 않습니다.
- 비밀번호 입력 필드(보안 입력)에서는 잠금이 비활성화됩니다.

## 사용 예시

- macOS 업데이트나 특정 앱이 입력 소스를 임의로 ABC로 전환하는 경우
- ABC 입력 소스를 제거할 수 없는 환경에서 Ongeul만 사용하고 싶은 경우
